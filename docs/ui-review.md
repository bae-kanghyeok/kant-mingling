# develop UI 검토 기록

2026-09-22, 회사 디자인 자료와 사용자가 제공한 최신 르탄이 PNG를 참고한 UI 개편이다. 게임 상태·명령·정답 공개 권한 계약은 유지한다. Figma 자료의 범위와 자산 출처는 [디자인 자료](design-assets.md)에 기록했다.

## 확인한 화면과 동작

로컬 개발 서버의 `/design-preview`에서 실제 UI 컴포넌트와 합성 데이터를 사용했다.

- 입장 화면: 데스크톱 2열과 모바일 세로 배치, 르탄이 원본 비율.
- 프로필: 선택 시 3/20에서 4/20으로 갱신, 합성 20문항 입력 후 제출 활성화.
- 수신 카드: 질문 원문과 선택한 답을 함께 표시. 비수신 화면에는 질문·답을 표시하지 않음.
- Ground Truth 재등장: 간단한 안내와 확인 후 닫힘.
- 정답 공개: Data Owner, 후속 대화 질문, 공개된 Noise와 실제 답을 구분.
- 관제: A/B/C조의 서로 다른 진행 상태, 연결 현황, 조별 제어와 호스트 메뉴. 데스크톱 우측 패널과 모바일 전체 화면.
- 360px 모바일에서 입장·프로필·수신 카드·정답 공개·관제의 가로 넘침 없음. 1440px 데스크톱 입장과 관제 레이아웃 확인.
- 현재 블록을 가로 3단계로 표시하고 `aria-current`로 구분. 미리보기 안내가 게임 본문을 가리지 않도록 배치.

## 코드 검사

- lint, TypeScript, 단위 테스트 57개, 콘텐츠 검사(프로필 20문항·후속 질문 80개), Production 빌드 통과.
- Production 서버에서 `/`는 200, `/design-preview`는 404이며 합성 갤러리 본문이 포함되지 않음.
- 실제 프로필의 기본 저장 경로는 기존 API다. 메모리 저장 함수는 개발 갤러리에서만 주입한다.
- 새 저장소에는 실제 행사 명단·접속 정보·과거 내부 문서·Figma 전체 사본을 포함하지 않는다.

## 검증의 한계와 다음 단계

이번 갤러리는 UI를 확인하기 위한 것이며 게임 엔진이나 DB 연동을 재현하지 않는다. DB 사용량 한도로 실제 DB 통합 테스트와 다중 기기 전체 게임은 이번 UI 개편에서 재실행하지 않았다. 실제 스마트폰·행사 Wi-Fi 확인도 남아 있다.

DB를 사용할 수 있게 되면 [전송량 최적화](troubleshooting.md)를 먼저 진행하고 개발 DB 통합 테스트, 세션 복구, 여러 기기에서의 블록 이동·투표·정답 비공개 검증을 수행한다. 결과를 확인한 뒤 develop의 main 반영과 운영 배포를 판단한다.
