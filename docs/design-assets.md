# 디자인 자료

회사 디자인 참조는 르탄이 캐릭터·브랜드 그래픽과 중립 색상 가이드다. 완성된 게임 UI 목업이 아니므로 화면 배치는 이 앱의 참가·프로필·게임·관제 흐름에 맞춰 구성한다.

Figma 원본 전체는 로컬 디자인 보관소에 보존하며 공개 저장소에는 올리지 않는다. 공개 앱에 쓰는 개별 자산은 public/brand에 두고 출처와 사용 범위를 이 문서에 기록한다. 회사 이름·로고·캐릭터에 별도의 개방형 라이선스를 부여하지 않는다.

main은 기존 화면을 보존한다. develop에서 새 르탄이 아이콘, 흰색·중립 회색과 붉은 강조색, 읽기 쉬운 카드·입력·관제 레이아웃을 적용한다. 콘텐츠와 게임 상태의 의미는 유지한다.
